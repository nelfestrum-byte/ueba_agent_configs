# HARDENING — план укрепления UEBA-стека и промпты для исполнения

В этой папке лежит:

- **[HARDENING_PLAN.md](HARDENING_PLAN.md)** — мастер-документ с 13 задачами + раздел Extras, шкалой приоритетов, обоснованиями, точками изменений, критериями готовности и граблями.
- **Промпт-файлы `PX-NN-<slug>.md`** — самодостаточные ТЗ для AI-агентов (Claude Code). Один промпт = одна итерация.

## Как пользоваться

1. Открыть новый сеанс Claude Code в корне репозитория.
2. Скопировать содержимое нужного промпт-файла из этой папки в первое сообщение к AI.
3. AI задаст уточняющие вопросы (если они есть в начале промпта), сделает pre-flight, выполнит итерацию, обновит документацию и зафиксирует изменения.

Каждый промпт — это **отдельная независимая итерация**, приносящая собственную ценность. Зависимости между задачами явно прописаны в начале каждого промпта; где зависимости отсутствуют — задача выполняется stand-alone.

## Структура каждого промпта

Все промпт-файлы построены по единому шаблону:

1. **Контекст и ссылки** — куда смотреть в репо (плюс README_FOR_AI, CLAUDE.md, раздел плана).
2. **Вопросы перед стартом** — что AI должен спросить у пользователя в первом ответе (если есть необходимость).
3. **Цель итерации** — какую ценность приносит **именно эта** задача независимо от остальных.
4. **Pre-flight проверки** — определение текущего состояния (что уже сделано из задачи или соседних).
5. **Реализация** — пошаговый план изменений.
6. **Что НЕ делать** — явные out-of-scope ограничения, чтобы не разрастаться.
7. **Проверка готовности** — acceptance criteria из плана.
8. **Финал** — обязательные пункты: обновить CLAUDE.md / README.md / README_FOR_AI.md / HARDENING_PLAN.md (статус задачи), закоммитить.

## Принципы

- **Каждая итерация атомарна и self-contained.** Промпт не предполагает, что соседняя задача уже выполнена. Если есть зависимость — она явно отмечена + указан фолбек.
- **AI должен задавать вопросы пользователю** в начале нового диалога, если в промпте есть секция "Вопросы перед стартом". Не делать предположений.
- **README_FOR_AI.md** — главный справочник по данным/ECS-схеме. Каждый промпт ссылается на него, потому что любая правка enrich-скриптов или audit-правил влияет на схему данных, и README_FOR_AI должен оставаться источником истины.
- **CLAUDE.md** — координирующий документ проекта. Обновлять на каждой итерации в разделах, которые задача затрагивает (источники, индексы, команды).
- **Коммит на итерацию** — один задачный промпт = один коммит (можно несколько, но в одной ветке/PR). После коммита обновить статус задачи в [HARDENING_PLAN.md](HARDENING_PLAN.md).

# HARDENING — текущие задачи и план

В этой папке лежит:

- **[HARDENING_PLAN.md](HARDENING_PLAN.md)** — подробные ТЗ на оставшиеся задачи: P1-03, P1-04, P3-01, P3-02, P3-03. Выполненные задачи v0.9 описаны в [docs/RELEASE_NOTES_0.9.md](../docs/RELEASE_NOTES_0.9.md).
- **Промпт-файлы `PX-NN-<slug>.md`** — самодостаточные ТЗ для AI-агентов (Claude Code). Один промпт = одна итерация.
- **[CONTAINER_BEHAVIOR_PLAN.md](CONTAINER_BEHAVIOR_PLAN.md)** — план построения поведенческой модели Docker-контейнеров (P4 Extras).

## Как пользоваться

1. Открыть новый сеанс Claude Code в корне репозитория.
2. Скопировать содержимое нужного промпт-файла в первое сообщение к AI.
3. AI задаст уточняющие вопросы (если они есть в начале промпта), сделает pre-flight, выполнит итерацию, обновит документацию и зафиксирует изменения.

Каждый промпт — **отдельная независимая итерация**, приносящая собственную ценность.

## Принципы

- **README_FOR_AI.md** — главный справочник по ECS-схеме. Любая правка enrich-скриптов или audit-правил должна его обновлять.

- **Один промпт = один коммит** (можно несколько в одной ветке). После коммита обновить статус в HARDENING_PLAN.md.
